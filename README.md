## ☁️ What is PiyuX Drive?

**PiyuX Drive** (formerly PiyuX Cloud v2) is a self-hosted cloud storage platform that leverages the Telegram API (MTProto) to provide virtually unlimited, highly secure, and lightning-fast file storage. With a beautiful web dashboard, shareable links, and built-in security mechanisms, it operates exactly like Google Drive but relies on Telegram's powerful infrastructure under the hood.

The application source is in the `Drive/` directory.

---

## ✨ Features

- **♾️ Unlimited Storage**: Backed securely by Telegram's infrastructure.
- **⚡ Blazing Fast**: Native streaming for videos and music directly from the dashboard.
- **🎨 Beautiful UI**: Modern, responsive, mobile-friendly interface designed for ease of use.
- **🔒 Enterprise-Grade Security**: Brute-force protection, automated database backups, secure session cookies, and encrypted data tracking.
- **🔗 Smart Sharing**: Create public, password-protected, or expiring links for any file or folder.
- **🛠️ Self-Hosted**: Run it anywhere—locally, on VPS, or PaaS providers like Render/Heroku.

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: SQLite3 (via `better-sqlite3` with WAL mode)
- **Telegram Core**: `gramjs` (MTProto implementation)
- **Frontend**: Vanilla HTML/JS/CSS (Highly optimized, zero bloat)
- **Image Processing**: `sharp` for blazing-fast on-the-fly thumbnails.

## 🚀 Getting Started (Local Development)

### 1. Prerequisites
- [Node.js](https://nodejs.org) (v20 or higher recommended)
- A Telegram Account
- Your Telegram `API_ID` and `API_HASH` (Get it from [my.telegram.org](https://my.telegram.org))

### 2. Installation

```bash
# Clone the repository
git clone https://github.com/Piyu242005/PiyuX.git

# Navigate into the drive folder
cd PiyuX/Drive

# Install dependencies
npm install

# Start the application
npm start
```

### 3. Setup
Once the server is running, navigate to `http://127.0.0.1:3001` in your browser. You will be greeted by the initial setup screen where you will create your admin account and bind your Telegram session securely.

## ☁️ Deploy on Render

This repository includes a `render.yaml` Blueprint for deployment.

1. Open [Render](https://render.com/) and create a new **Blueprint**.
2. Connect the `Piyu242005/PiyuX` repository and select the `main` branch.
3. Review the service settings and create the service.
4. When prompted, set `PUBLIC_URL` to the exact public Render URL, without a trailing slash (for example, `https://your-service.onrender.com`).
5. Keep `SECRET` generated by Render. Do not commit it or share it publicly.
6. Once deployment completes, open the service URL. Create the administrator account, then connect Telegram using your Telegram API ID and API hash.

### Render configuration

The Blueprint sets:
- **Root directory:** `Drive`
- **Build command:** `npm ci`
- **Start command:** `npm start`
- **Health check:** `/api/health`
- **Persistent disk:** mounted at `/opt/render/project/src/Drive/data`
- **Runtime:** Node.js (Node 20 or later)

The persistent disk stores the SQLite database, generated backups, Telegram session data held in SQLite, uploaded branding files, and temporary application data. Keep a persistent disk attached to preserve this state across restarts and deployments.

## 🛡️ Security & Reliability

PiyuX Drive prioritizes the safety of your files and accounts:
- **Rate-Limiting**: Built-in protection against brute-force login attempts.
- **Automated Backups**: Your SQLite metadata is automatically backed up daily to prevent data loss.
- **Secure File Handling**: OS-native temp directories and robust OS pathing prevent directory traversal or failing uploads.
- **Important Notes**: Set `PUBLIC_URL` correctly for share links. `SECRET` must remain stable across restarts to avoid invalidating sessions. The `/api/health` route checks that the web process responds.
